# 철학

까치는 이미 쓰는 에이전트를 집에 들이는 가벼운 집 비서다. Home Assistant 가 집에 AI 를 붙인다면, 까치는 쓰던 에이전트(구독, 도구, 기억)에 집을 붙인다. 기능을 더할지, 무엇을 기본값으로 둘지는 아래 세 가지로 정한다.

## 1. 가볍게

설치는 한 번으로 끝나고, VM 이나 허브 없이 지금 있는 컴퓨터와 안 쓰는 폰으로 돈다.

- 공기계는 앱을 깔지 않고 웹페이지 하나로 붙는다.
- core 는 에이전트 루프와 MCP 연결만 맡는다. 기기, 기억, 집은 MCP 서비스로 꽂는다.
- 무거운 것은 필요해질 때 붙이는 선택이다. Home Assistant 는 실제 전구나 카메라가 생기면 ha-mcp 로 붙이고([ha.md](ha.md)), 로컬 LLM 은 그걸 돌릴 수 있는 컴퓨터에서만 쓴다.

## 2. 내 것으로

기억은 내 파일이고, 데이터는 내 컴퓨터에 있다.

- 기억은 git 레포의 Markdown 이다. 직접 읽고 고치고 옮길 수 있고, 바뀔 때마다 커밋이 남아 되돌릴 수 있다.
- 백업은 사용자가 고른 곳으로, 고를 때만 한다. 원격이 있어도 `KKACHI_MEMORY_SYNC` 를 켜기 전에는 pull 도 push 도 하지 않는다. GitHub 대신 USB 나 NAS 의 bare 레포여도 된다.
- 답을 읽는 목소리는 기본이 폰과 공기계에 들어 있는 목소리다. 문장이 까치 서버나 음성 서비스로 가지 않는다. Edge TTS 목소리는 고를 때만 쓴다.
- 공기계가 보고 들은 것(사진, 소리 크기, 센서)은 전달만 하고 저장하지 않는다. 커밋에는 `[사진 N장]` 만 남는다.
- 까치는 tailnet 안에서만 열린다. 공개 인터넷(Tailscale Funnel)에는 내놓지 않는다.
- 까치가 스스로 부르는 외부 서비스는 LLM 말고는 없게 한다. 로컬로 할 수 있는 일은 로컬이 기본이고, 외부 API 는 고를 때만 쓴다. LLM 은 쓰던 구독을 쓰거나 로컬 모델로 바꿀 수 있다.

이 원칙은 까치가 스스로 하는 일에 적용한다. 사용자가 가져온 MCP 나 도구가 외부 서비스를 부르는 것은 사용자의 선택이다.

## 3. 쓰던 그대로

쓰던 에이전트의 구독, MCP, 스킬을 그대로 가져온다.

- 런타임은 Pi 하나다. Claude Code 나 Codex 를 따로 지원하지 않고, 그쪽 설정을 Pi 로 가져온다. harness 마다 연결부를 만들면 1번이 깨진다.
- 모델은 Pi 에 로그인한 구독(Claude, ChatGPT 등)을 그대로 쓴다.
- MCP 는 Claude Code, Codex, Cursor, VS Code 에 이미 붙여 둔 것을 pi-mcp-adapter 가 가져온다. 어댑터가 서버들을 도구 하나(`mcp`)로 묶고 필요할 때 연결해서, 서버가 늘어도 매 턴 도구 정의가 불어나지 않는다.
- 스킬과 `AGENTS.md` 도 Pi 가 읽는 자리에 있으면 그대로 쓴다.
- 붙여 쓸 만한 MCP 는 [extensions.md](extensions.md) 에 모아 둔다. 로컬로 도는 것이 먼저다.
- 반대 방향도 열려 있다. 까치의 기억과 공기계는 MCP 라서 Claude Desktop 이나 Codex 가 까치를 쓸 수 있다.

## 부딪힐 때

- 1번과 2번: 로컬 LLM 은 GPU 없는 노트북에서 느리고 도구 호출과 한국어가 약하다. LLM 만은 구독 API 를 기본으로 두고 로컬 모델은 선택으로 둔다. CPU 로 충분한 일은 로컬이 기본이다. 음성 인식은 재 보니 충분하지 않았다(아래).
- 1번과 3번: harness 를 여럿 지원하지 않는다. 런타임은 Pi 하나이고 나머지는 가져온다.
- 3번과 안전: 공기계에는 방에 있는 누구나 말할 수 있다. 가져온 MCP 는 폰 앱 대화에만 기본으로 열고, 공기계에는 고른 것만 연다.
- 2번과 집: 홈캠 녹화처럼 오래 남겨야 하는 일은 까치가 아니라 HA 같은 도구가 맡는다. 까치는 전달만 한다.

## 아직 못 지키는 것

2026-11-25 기준이다. 할 일은 [plan.md](plan.md) 의 M12.

- 음성 인식(Groq Whisper)과 받아쓴 말 다듬기(Groq LLM)가 외부 API 다. 로컬 Whisper(whisper.cpp)는 설정만으로 쓸 수 있지만, GPU 없는 노트북에서 정확한 모델(small)이 한 문장에 10초쯤 걸려 기본으로 두지 않았다([design.md](design.md) "로컬 받아쓰기"). 다듬기는 대화 모델이 맡거나 뺀다.
- `bun run init` 이 다른 harness 의 MCP 를 가져오지 않는다. pi-mcp-adapter 의 가져오기를 init 에 넣는다.
- 공기계 대화가 "전체" 도구이면 사용자의 MCP 가 모두 따라간다. 가져온 MCP 는 공기계용으로 따로 고르게 한다.
- 설치가 한 번에 끝나지 않는다. Git, Bun, Pi, Tailscale 을 먼저 깔아야 한다.
