# 철학

까치는 설치가 쉽고 가벼운 집 비서다. Home Assistant 는 전용 OS 나 VM 을 먼저 깔아야 하지만, 까치는 명령 하나로 지금 있는 컴퓨터에 깔리고 안 쓰는 폰이 웹페이지 하나로 기기가 된다. 기능을 더할지, 무엇을 기본값으로 둘지는 아래 두 가지로 정한다.

## 1. 가볍게

설치는 한 번으로 끝나고, VM 이나 허브 없이 지금 있는 컴퓨터와 안 쓰는 폰으로 돈다.

- 공기계는 앱을 깔지 않고 웹페이지 하나로 붙는다.
- core 는 에이전트 루프와 MCP 연결만 맡는다. 기기, 기억, 집은 MCP 서비스로 꽂는다.
- 에이전트는 Pi 하나다. Claude Code 나 Codex 를 따로 지원하지 않는다. harness 마다 연결부를 만들면 가볍지 않다. 모델은 Pi 에 로그인한 구독(Claude, ChatGPT 등)을 쓰고, 다른 도구에 붙여 둔 MCP 는 설치할 때 가져올 수 있다(pi-mcp-adapter).
- 넓히는 방법은 MCP 하나다. 붙여 쓸 만한 서버는 [extensions.md](extensions.md) 에 모아 둔다. 까치의 기억과 공기계도 MCP 라서 Claude Desktop 이나 Codex 가 까치를 쓸 수 있다.
- 무거운 것은 필요해질 때 붙이는 선택이다. Home Assistant 는 실제 전구나 카메라가 생기면 ha-mcp 로 붙이고([ha.md](ha.md)), 로컬 모델(LLM, 음성 인식, 목소리)은 그걸 돌릴 수 있는 컴퓨터에서만 쓴다.

## 2. 내 것으로

기억은 내 파일이고, 데이터는 내 컴퓨터에 있다.

- 기억은 git 레포의 Markdown 이다. 직접 읽고 고치고 옮길 수 있고, 바뀔 때마다 커밋이 남아 되돌릴 수 있다.
- 백업은 사용자가 고른 곳으로, 고를 때만 한다. 원격이 있어도 `KKACHI_MEMORY_SYNC` 를 켜기 전에는 pull 도 push 도 하지 않는다. GitHub 대신 USB 나 NAS 의 bare 레포여도 된다.
- 답을 읽는 목소리는 기본이 폰과 공기계에 들어 있는 목소리다. 문장이 까치 서버나 음성 서비스로 가지 않는다. 서버가 만드는 목소리는 고를 때만 쓴다. 이 컴퓨터에서 만드는 Supertonic 3 와 온라인인 Edge TTS 가 있다.
- 공기계가 보고 들은 것(사진, 소리 크기, 센서)은 전달만 하고 저장하지 않는다. 커밋에는 `[사진 N장]` 만 남는다.
- 까치는 tailnet 안에서만 열린다. 공개 인터넷(Tailscale Funnel)에는 내놓지 않는다.
- 까치가 스스로 부르는 외부 서비스는 LLM 말고는 없게 한다. 로컬로 할 수 있는 일은 로컬이 기본이고, 외부 API 는 고를 때만 쓴다. LLM 은 구독을 쓰거나 로컬 모델로 바꿀 수 있다.

이 원칙은 까치가 스스로 하는 일에 적용한다. 사용자가 가져온 MCP 나 도구가 외부 서비스를 부르는 것은 사용자의 선택이다.

## 부딪힐 때

- 1번과 2번: 로컬 LLM 은 GPU 없는 노트북에서 느리고 도구 호출과 한국어가 약하다. LLM 만은 구독 API 를 기본으로 두고 로컬 모델은 선택으로 둔다. CPU 로 충분한 일은 로컬이 기본이다. 음성 인식은 재 보니 충분하지 않았다(아래).
- 가져온 MCP 와 안전: 공기계에는 방에 있는 누구나 말할 수 있다. 혼자 쓰는 집이라는 가정으로 공기계도 까치 홈과 같은 도구를 쓰고, 개인적인 내용도 소리로 말한다. 손님이 오는 곳의 기기는 까치 홈에서 그 기기의 음성을 닫는다.
- 2번과 집: 홈캠 녹화처럼 오래 남겨야 하는 일은 까치가 아니라 HA 같은 도구가 맡는다. 까치는 전달만 한다.

## 아직 못 지키는 것

- 음성 인식의 기본값(Groq Whisper)이 외부 API 다. 받아쓴 말 다듬기(Groq LLM)는 고를 때만 켜진다. 로컬로는 작은 GPU 가 있으면 Qwen3-ASR 이 1~2초에 받아쓰지만 따로 띄워야 하고, GPU 가 없으면 한 문장에 3~10초가 걸려 기본으로 두지 않았다([design.md](design.md) "로컬 받아쓰기").
- 설치가 아직 가볍지만은 않다. 명령 하나가 Git, Bun, Pi, Tailscale 을 깔고, 로컬 음성 모델을 쓰려면 프로그램과 모델(0.4~2 GB)을 더 받아 따로 띄워야 한다.
- 설치 명령 하나(`install.sh`, `install.ps1`)가 빠진 도구를 깔고 설정까지 이어 가지만, 아무것도 없는 컴퓨터에서 끝까지 돌려 보지는 않았다.
