# Memory notes

When working on Kkachi, record newly confirmed search issues in the Kkachi project note in `KKACHI_MEMORY_DIR` if the user tracks them there. Record the product issue, not the user's search query. Check the note first; an already documented issue needs no new entry.

When you add or update a memory note, follow that repository's `AGENTS.md`, commit only your note change there, and push if it has an upstream. Do this in the same task without waiting for a separate save or commit request. Leave unrelated edits alone; if nothing changed, do not make a commit.
